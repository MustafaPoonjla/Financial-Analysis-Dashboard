# Financial Analysis Dashboard

An interactive financial performance dashboard built with Power BI, analysing 
sales, profit, and cost data across 5 countries, 5 business segments, and 
6 product lines over 2013–2014.

## Dashboard Preview
![Financial Analysis Dashboard](Financial%20Analysis%P1.png)

## What This Dashboard Shows

The dashboard analyses 700 financial transactions totalling $118M in sales 
across Germany, France, Canada, the US, and Mexico — answering key questions:

- Which segments and products generate the most profit?
- Where are margins being eroded by discounts or high COGS?
- How did financial performance shift between 2013 and 2014?
- Which markets should be prioritised for growth?

## Key Insights

- **Government** segment drove the most profit ($11.4M), while **Enterprise** 
  was the only segment running at a loss (-$614K)
- **Paseo** was the top product by profit ($4.8M); **Carretera** the weakest ($1.8M)
- **France** and **Germany** led all markets in profitability
- Sales grew **249%** from 2013 ($26.4M) to 2014 ($92.3M)
- Overall profit margin sat at **14.2%**, with $9.2M lost to discounts

## Features

- KPI cards for total sales, profit, COGS, and discount impact
- Profit and sales breakdown by segment, country, and product
- Year-over-year trend comparison (2013 vs 2014)
- Discount band analysis showing margin erosion by tier
- Interactive slicers for country, segment, product, and year
